# TrialGuard Test Data

`trialguard-test-import.json` is a synthetic, de-identified dataset for exercising the local application. It is not clinical data and must not be used for medical or regulatory decisions.

It intentionally includes:

- A healthy site with complete records
- An out-of-window visit
- A missing visit
- An incorrect dose
- A prohibited medication
- A missing assessment
- A late data-entry event
