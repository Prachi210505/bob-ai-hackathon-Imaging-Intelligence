# TrialGuard Presentation

Add the final slide deck as `slides.pdf` (preferred) or `slides.pptx` before submission.

## Accepted Formats

  slides.pdf      ← Preferred (universally viewable)
  slides.pptx     ← Acceptable
  slides.key      ← Acceptable (macOS Keynote)

Rename your file to `slides.pdf` (or `slides.pptx`) so the evaluation
pipeline can locate it reliably.

## Recommended Slide Structure (5–8 slides)

  Slide 1: TrialGuard — Imaging Intelligence, AI track
  Slide 2: Clinical trial monitoring problem and affected users
  Slide 3: Evidence-backed protocol analysis and risk radar
  Slide 4: FastAPI, SQLite, frontend, and analysis architecture
  Slide 5: Live demo flow: import, prioritize, investigate, and create CAPA
  Slide 6: IBM Bob adapter boundary and current integration limitation
  Slide 7: Impact, reproducibility, and next steps
  Slide 8: Team — add names and roles when finalized

## Tips

- Keep slides visual — diagrams beat bullet points
- One idea per slide
- Font size minimum 24pt for readability
- Do not paste large code blocks into slides — reference the repo instead
